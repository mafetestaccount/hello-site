# Hello there

A small one-page site: an illustrated gentleman in 18th-century dress waves and greets visitors with a speech bubble saying "Hello there". Inspired by the look of the Hamilton era; the character is an original drawing.

## View it

Once GitHub Pages is turned on, the site lives at:

`https://YOUR-USERNAME.github.io/hello-site/`

## Run it locally

Open `index.html` in any browser. There is nothing to install.

## Files

- `index.html` - the whole site (HTML, CSS and the drawing in one file)
- `README.md` - this description
